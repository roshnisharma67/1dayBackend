what is contributing file in shorts
A CONTRIBUTING.md file in GitHub explains how other developers can contribute to your project.

It usually includes:

Setup instructions — how to run the project locally.

Coding guidelines — rules to follow when writing code.

Bug reporting — how to report issues.

Pull requests — how to submit code changes for review.

In short:

README.md → Explains the project.

CONTRIBUTING.md → Explains how to contribute to the project.
